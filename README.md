# stow-dotfiles
Projeto de arquivos de configuração para meus setups pessoais.
# Initial Setup:
- Install [Starship](https://starship.rs/):
```bash 
curl -sS https://starship.rs/install.sh | sh
```
- Execute `stow fish` to get it's setup.
- Go to that new profile.

## Programs setup
```bash 
 brew install fish stow bat
```

# Install and Configure: 
Since you're free to choose between any software to install, you basically need to install the service and ¨stow" it.
## Yazi:
```bash 
 brew install yazi 
```

```bash 
stow yazi
```

## Lazygit:
```bash 
 brew install lazygit
```

```bash 
stow lazygit
```


## Lazydocker:
```bash 
 brew install lazydocker
```

```bash 
stow lazydocker
```


## Neovim setup
```bash 
 brew install neovim tree-sitter tree-sitter-cli
```

```bash 
stow nvim
```
